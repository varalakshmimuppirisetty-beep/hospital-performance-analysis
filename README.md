# 🏥 Hospital Performance Analysis

**Author:** M. Varalakshmi
**Tools:** Python (pandas, matplotlib, seaborn)
**Data:** FY 2026 CMS Hospital Readmissions Reduction Program

## Objective
Analyse hospital readmission performance across the USA 
using real government data.

## Key Findings
- 48.1% of hospital-condition pairs exceed CMS penalty threshold
- Hip/Knee Replacement shows highest variation in readmission ratios
- All conditions average above the penalty threshold of 1.0

- `FY_2026_Hospital_Readmissions_Reduction_Program_Hospital.csv` — dataset
